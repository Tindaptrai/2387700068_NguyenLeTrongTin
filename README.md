# 2387700068_NguyenLeTrongTin

Thực hành Lập trình An toàn Thông tin.

## Nội dung

- [Buổi 1](Buoi%201): kiểm thử và phân tích các điểm yếu bảo mật trong validator,
  pre-commit hook và hệ thống logging.
- [Buổi 2 - Lab 1](Buoi%202/Lab1): bộ công cụ mã hóa AES-GCM, RSA, Argon2,
  CLI, GUI và Flask API.
- [Buổi 2 - Lab 2](Buoi%202/Lab2): mô phỏng hạ tầng khóa công khai với Root CA,
  Intermediate CA, chứng chỉ người dùng và CRL.
- [Buổi 3 - Lab 03](Buoi%203): SecureChat dùng TLS và AES, NetRecon CLI/web
  với quét cổng, nhận dạng dịch vụ, bảng ARP và gửi kết quả qua email.
- [Buổi 4 - Lab 04](Buoi%204): Web Vulnerability Scanner và JWT Security Tools,
  kèm hướng dẫn cài đặt, chạy ứng dụng/API, bộ kiểm thử và ảnh minh họa.
- [Buổi 5 - Lab 05](Buoi%205): SAST phân tích mã Python và xuất SARIF;
  DAST theo dõi tiến trình, bộ đếm mạng và Flask API, kèm ảnh từng bước thực hành.
- [Buổi 6 - Lab 06](Buoi%206): demo DevSecOps với test, SAST, quét dependency, secret và IaC trong GitHub Actions; có README hướng dẫn và ảnh minh họa từng bước.
